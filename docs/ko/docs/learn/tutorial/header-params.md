## 자동 변환

대부분의 표준 헤더는 `-` (하이픈)으로 구분됩니다. 하지만 Python에서 `user-agent`와 같은 변수는 유효하지 않습니다.

따라서 기본적으로 **Nexify**는 내부적으로 매개변수의 이름을 `_` (밑줄)에서 `-` (하이픈)으로 변환하여  헤더를 추출하고 문서화합니다.

또한 HTTP 헤더는 대소문자를 구분하지 않습니다.
