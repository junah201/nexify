# 자습서

이 자습서은 단계별로 Nexify의 거의 모든 기능에 대해서 설명합니다.

각 단계는 이전 단계에 기반하는 순차적인 구조로 작성되었지만, 각 주제별로 구분되어 있기 때문에 필요에 따라 특정 단계로 바로 이동하여 필요한 내용을 바로 확인할 수 있습니다.


# 자습서 내 코드

자습서 내의 모든 코드는 복사하여 바로 사용하실 수 있습니다. 모든 코드는 실제로 테스트된 파이썬 파일입니다.

코드를 작성하거나 복사, 편집할 때, 로컬 환경에서 실행하는 것을 권장합니다.

로컬 환경에서 Nexify를 사용한다면, 모든 타입 검사와 자동완성 등 작성해야 하는 코드가 얼마나 적인지 보면서 Nexify의 이점을 비로소 경험할 수 있습니다.

---

# Nexify 설치하기

가장 첫번째 단계는 Nexify를 설치하는 것입니다.

자습서에서는 모든 선택적인 의존성 및 기능을 함께 설치하는 것을 추천합니다.

<div class="termy">

```console
$ pip install "nexify[cli]"

---> 100%
```

</div>

/// info
일부 터미널 환경에서는 `"nexify[cli]"`처럼 따옴표를 사용해야 올바르게 설치됩니다.
///


/// info
`nexify[cli]`는 개발 환경에 필요한 여러 의존성을 포함하고 있습니다.
만약 Nexify를 프로덕션에 배포하려는 경우 다음과 같이 설치하시면 됩니다.

```py
pip install nexify
```
///
